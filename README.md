# Diabetes Risk Prediction 🩺

## 📌 Project Overview

This project focuses on predicting the risk of diabetes using patient-related demographic, medical history, and lifestyle data.

## 🎯 Objective

The objective is to build a machine learning classification model that can predict diabetes risk based on relevant patient features.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Logistic Regression

## 🔍 Project Workflow

1. Data Exploration
2. Data Preprocessing
3. Handling Missing Values
4. Feature Selection
5. Feature Scaling
6. Model Training
7. Model Evaluation

## 🤖 Machine Learning Model

**Logistic Regression** was used as the classification algorithm.

## 📊 Evaluation

The model was evaluated using:

* Accuracy Score
* Classification Report
* Confusion Matrix

## 📁 Files

* `Diabetes_Risk_Prediction.ipynb` — Complete project notebook
* `diabetes.csv` — Dataset, if included
